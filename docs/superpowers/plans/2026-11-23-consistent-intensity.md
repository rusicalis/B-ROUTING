# Consistent intensity within the selected time

User authorized fixing the audit's three defects: pre-start/live inconsistency, merged capped doses, and finite sessions growing far beyond30/40/50/60minutes.

Use one absolute Normal baseline and policy: Normal baseline; Hard per-set repetitions/timed work ×1.25; Extreme ×1.5. Round to meaningful whole counts with strict separation, including tiny values and previously capped holds. These are app workload presets, not measured percentages of individual maximal strength. Keep equipment, selected exercises, earned difficulty progression, movement tempo and rests unchanged.

Finite plans rebalance complete sets within the selected duration, retaining every exercise and balanced distribution. Do not add time or idle padding to represent intensity. Sunday remains unlimited rounds with Normal5/10/15 and round-end30seconds rest. Explicit saved presets and free/cardio use the same policy.

Live changes preserve completed credits, current dose, elapsed and current rest. New future prescriptions come from the Normal baseline, never compounded from the last intensity. Reconcile duration and intensity through one helper; account for actual elapsed time. Report unavoidable overflow when already spent/current/mandatory work exceeds the chosen target.

Test shared policy matrices, pre-start/live parity, caps, circuit grouping, time estimates, repeated toggles, reload, duration changes and missed/completed exercise navigation. Exercise the actual UI in Chrome/WebKit. Publish the authorized GitHub update and verify Pages/ZIP.

Training context: [ACSM2026 guidance](https://acsm.org/resistance-training-guidelines-update-2026/) emphasizes individual goals, effort and suitable volume; it does not define these three app labels or prescribe the25/50percent app rules.
