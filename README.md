# BURNING ROUTINE 4.0

운동·할 일 관리 PWA. [앱 실행](https://rusicalis.github.io/B-ROUTING/?view=workout)

## 요청한 주간 프리셋과 기본 대체 동작

| 요일 | 기본 순서 |
|---|---|
| 월·목 | 푸시업 → 파이크 푸시업 → 누운 케틀벨 삼두 → 의자 딥스 → 리버스 플랭크 |
| 화·금 | 케틀벨 컬 → 원암 숄더 프레스 → 데드리프트 → 복근 → 밴드 사이드 레이즈 |
| 수·토 | 케틀벨 원암 로우 → 스쿼트 → 리버스 플랭크 |
| 일 | 로우 양쪽 → 푸시업 → 스쿼트 서킷, 이후 복근·리버스 플랭크 |

기본은 **30분 시간 맞춤**입니다. 실제 세트 시간, 양쪽 운동, 휴식을 합산하며 남는 시간을 숨은 휴식으로 채우지 않습니다. 설정한 분량에 따라 반복·유지 시간·세트와 보조 동작을 늘립니다. 준비·마무리 운동과 점프는 없습니다.

기본 시간 맞춤은 정확한 그림을 우선해 누운 케틀벨 삼두→맨몸 무릎 삼두 익스텐션, 케틀벨 컬→원암 컨센트레이션 컬, 짧은 밴드 사이드 레이즈→맨몸 프론 Y 레이즈로 대체합니다. 보조 밴드 W/프론 W도 그림이 있는 동작으로 바꿉니다. 밴드는 요청 원안에 남기며 기본 루틴에 잘못된 긴 밴드 그림을 쓰지 않습니다.

**원안 목표 수량**은 따로 선택합니다. 월·목 푸시업100회, 두 삼두 운동 각각10세트, 유지60초×5세트와 일요일은 최신 요청에 따라4라운드로 줄입니다. 30분보다 긴 날도 실제 예상 시간을 그대로 표시합니다. 원안에서 지정하지 않은 수량은 각 운동에 표시된 기본값으로 산정합니다.

세트 사이30초, 다른 운동으로 넘어갈 때60초입니다. 일요일도 스쿼트에서 다음 라운드 로우로 바뀔 때60초이며 마지막 세트 뒤에는 휴식이 없습니다. 일요일은 기본35분(실제 예상 약34분), 별도 목표는4라운드+복근·리버스 플랭크60초×5세트로 약36분입니다. 일요일 시간은30~40분 범위로 설정됩니다. 실제 사용자가 세트를 끝내는 속도와 휴식 건너뛰기에 따라 실제 시간은 달라집니다.

요청 배치를 우선하며, 일→월 가슴·삼두나 월→화 어깨처럼 협력근 사용이 이어질 수 있음을 화면에 표시합니다. 이전의 모든 부위 주3회·연속일 없음 주장은 새 주간표에 적용하지 않습니다.

## 내 프리셋과 성장

루틴 변경 → 시간·수량 선택 → '운동량 편집·내 프리셋 저장'에서 세트와 횟수/초를 편집하고 이름을 붙여 저장합니다. 저장 프리셋은 선택·삭제할 수 있고 새로고침 후에도 유지됩니다. 서킷 라운드는 첫 운동의 세트 수로 맞춥니다. 시간 맞춤에서는 저장 당시 분량을 기준으로 시간 변경에 맞춰 조절하고, 원안 목표에서는 저장 수량을 그대로 사용합니다.

모든 세트를 실제 완료하고 '여유 있게 완료'를 선택한 날에만 다음 단계로 증가합니다. 하루 같은 트랙은1회만 상승하며 '힘들었어요'는 유지, '통증'은 하향합니다. 총 작업량의 급증 없이 한 동작의 유지 시간 또는 제어 템포를 소폭 늘리며13단계에서 상한을 둡니다. 분량을 늘리는 주된 조절은 운동 시간 설정입니다. 기존 할 일·테마·기록·성장 트랙과 로컬 저장 키는 보존합니다.

## 그림과 화면 유지

실사 영상과 실시간3D를 사용하지 않습니다. 해부학 그림 GIF는 운동 타이머와 동기화하고 일시정지·휴식 때 멈춥니다. 양쪽 운동은 측면을 전환합니다. 실제 장비와 다른 그림을 해당 동작으로 표시하지 않습니다. 원격 그림은 처음 볼 때 인터넷이 필요하고 표시 후 캐시합니다. 출처·이용 조건과 외부 서비스 의존은 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 기재합니다.

설정의 '화면 자동 꺼짐 방지'는 기본 켜짐입니다. 보이는 앱에서 Screen Wake Lock을 요청하고, 화면 복귀/터치 시 재요청합니다. 다른 앱 전환·페이지 종료·설정 해제 시 해제합니다. 지원 안 됨·요청 거부·실제 유지 중을 구분합니다. iOS Safari는16.4 이상, 홈 화면 웹 앱은18.4 이상의 지원이 필요하며 저전력 상태 등의 기기 정책으로 요청이 거부될 수 있습니다. 강제로 시스템 정책을 우회하지 않습니다.

375×629 Safari 영역과375×812 홈 화면 크기, WebKit, 최소44px 터치 영역과 하단 안전 여백을 검증합니다. 실제 iPhone 하드웨어에서 배터리/자동 잠금 시간을 측정한 것은 아닙니다.

## 검증

빌드 없이 GitHub Pages에 루트를 게시합니다. 파일 더블클릭 대신 HTTP 서버로 실행합니다.

```sh
node --test
node --check app.js
node --check illustrated-guide.mjs
node --check service-worker.js
```

Playwright Core+Chrome/WebKit 검증은 scripts/ 아래에 있습니다. PLAYWRIGHT_CORE_PATH, PLAYWRIGHT_BROWSERS_PATH, CHROME_PATH, TEST_URL, TEST_OUTPUT_DIR 설정을 사용합니다. preset-program.cjs는 프리셋·휴식 경계·저장·화면 유지 모의 API를 검증합니다. GitHub main 업로드 시 Workout checks와 Pages가 자동 실행됩니다.
