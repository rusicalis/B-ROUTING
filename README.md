# BURNING ROUTINE 2.0

기존 일정·할 일 관리와 맨몸 + 12kg 케틀벨 1개 운동을 함께 사용하는 한국어 PWA입니다.

실행: https://rusicalis.github.io/B-ROUTING/?view=workout

## 운동 사용법

1. 운동 탭에서 전신 또는 원하는 부위를 선택합니다. 가슴/등/하체/둔근/어깨/팔/코어를 여러 개 조합할 수 있습니다.
2. 루틴 1로 시작합니다. 루틴 2/3은 다른 동작 조합이며, 각각 성장 기록이 따로 유지됩니다.
3. 운동 카드를 눌러 3D 동작과 3단계 자세 설명을 먼저 확인합니다. 드래그 회전, 정면/측면/후면, 0.5~1.5배 재생, 구간 탐색을 지원합니다.
4. 운동 시작 후 실제로 세트를 마쳤을 때 ‘세트 완료’를 누릅니다. 타이머는 동작 가이드이며 실제 수행 여부를 자동 판정하지 않습니다. 한쪽 운동은 양쪽 모두 마친 뒤 확인합니다.
5. 모든 세트가 끝나면 컨디션을 선택합니다. ‘여유 있게 완료’는 다음 운동 단계 +1, ‘힘들었어요’는 유지, ‘통증이 있었어요’는 -1입니다. 같은 루틴은 하루 1회까지 상승합니다.
6. 무게는 12kg으로 고정하고 반복 수/유지 시간, 세트 수, 템포를 올립니다. 최대 13단계, 4세트, 16회, 유지 운동 45초입니다. 완료하지 않으면 올라가지 않습니다.

‘직접 운동을 골라 루틴 만들기’에서 최대 10개 동작을 추가할 수 있습니다. 12kg이 부담스러운 동작은 미리보기 설명의 ‘맨몸 동작으로 변경’을 이용하세요. 운동 중 변경하려면 ‘오늘은 여기까지’로 먼저 종료합니다. 같은 부위는 충분히 회복한 뒤 운동하세요.

화면을 벗어나면 운동이 일시정지됩니다. 같은 날 다시 열면 중간 운동을 일시정지 상태로 이어갈 수 있습니다. 기존 토요일 러닝 일정은 그대로 유지하며, 실내 루틴 완료로 러닝 완료를 대신 체크하지 않습니다.

## 기존 데이터와 오프라인

- 기존 localStorage 키 `burning-routine-local-v150`를 유지합니다. 할 일, 완료 체크, 달성 그래프, 테마를 유지합니다.
- 이전 밴드 운동 등 지원하지 않는 사용자 동작은 새 운동 목록에서 제외됩니다. 새 성장 시스템은 LEVEL 01부터 시작하고 이전 기록은 보관합니다.
- 첫 온라인 접속 및 서비스 워커 설치 이후에는 3D 라이브러리까지 오프라인으로 동작합니다. 3D를 지원하지 않는 기기에서는 자세 설명으로 진행할 수 있습니다.
- 기존 설치 앱에 이전 화면이 남으면 온라인 상태에서 새로고침 후 앱을 닫았다 다시 열어 주세요.
- 데이터는 사용 중인 브라우저/기기에 저장되며 다른 기기와 자동 동기화되지 않습니다. 동일 주소와 브라우저로 이용하세요.
- 3D는 동작 이해를 위한 직접 제작 관절형 일러스트이며 실제 촬영/모션 캡처 또는 자세 판정 기능이 아닙니다.

## 개발과 검증

빌드나 패키지 설치 없이 저장소 루트가 정적 사이트입니다. ES 모듈을 사용하므로 파일 더블클릭 대신 HTTP 서버 또는 GitHub Pages로 여세요.

```sh
node --test
node --check app.js
node --check motion-studio.js
node --check service-worker.js
```

브라우저 검증 스크립트: `scripts/browser-smoke.cjs`. Playwright Core와 Chrome이 필요합니다. `TEST_URL`, `PLAYWRIGHT_CORE_PATH`, `CHROME_PATH`, `TEST_OUTPUT_DIR` 환경변수로 실행 환경을 지정할 수 있습니다.

GitHub main에 변경사항이 올라가면 기존 GitHub Pages 설정이 자동 배포합니다. `.github/workflows/checks.yml`는 운동 엔진 및 문법을 자동 검사합니다.

30개 운동과 자세/세션 로직은 `workout-engine.mjs`, `motion-studio.js`, `app.js`에 분리했습니다. 외부 라이선스 및 참고 자료는 `THIRD_PARTY_NOTICES.md`를 확인하세요.
