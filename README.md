# BURNING ROUTINE 4.2.2

운동·할 일 관리 PWA. [앱 실행](https://rusicalis.github.io/B-ROUTING/?view=workout&release=422)

## 운동 조작

그림 중앙 ▶로 시작합니다. 운동·휴식 중 그림을 누르면 멈추며, 중앙에 재생과 건너뛰기가 나타납니다. 운동 건너뛰기와 좌우 이동은 완료를 부여하지 않습니다. 설정된 동작 시간이 끝나면 세트를 자동 완료하며, 다른 앱으로 전환하면 일시정지됩니다.

좌우 화살표는 **미완료 운동만** 탐색합니다. 1번을 마치고 2번을 건너뛰었다면 3·4번에서 왼쪽으로 돌아가 2번을 마칠 수 있습니다. 완료한 1번은 다시 나타나지 않습니다. 모든 세트와 마지막 컨디션을 저장해야 전체 완료로 기록합니다. 별도 '남은 운동' 목록은 없습니다.

건너뛰기는 글자 없는 검은 원형 아이콘이며 재생 버튼과 같은 48px 크기입니다. 화면 읽기용 이름과 데스크톱 툴팁은 유지합니다.

운동 전뿐 아니라 운동 중·일시정지·휴식 중에도 30·40·50·60분을 선택할 수 있습니다. 완료한 운동과 현재 세트의 시간·수량은 보존하고 앞으로 할 운동량만 바꿉니다. 바꾼 시간은 새로고침 뒤에도 유지됩니다. 이미 완료했거나 진행 중인 운동량이 짧은 목표보다 많다면 보호한 운동량을 우선합니다. 일요일 무제한 서킷에는 시간 선택을 적용하지 않습니다.

기존 세트 타이머가 운동과 휴식 시간을 번갈아 표시합니다. 별도 휴식 카드는 없으며 운동 방법은 타이머 아래에 있습니다. 휴식 중 그림은 실제 다음 세트를 미리 보여줍니다.

## 기본 주간 루틴

| 요일 | 부위 | 기본 동작 |
|---|---|---|
| 월·목 | 가슴 · 삼두 · 복근 | 푸시업, 와이드 푸시업, 맨몸 삼두 익스텐션, 크런치, 플랭크 |
| 화·금 | 등 · 이두 · 복근 | 케틀벨 원암 로우, 프론 Y 레이즈, 케틀벨 컨센트레이션 컬, 크런치, 플랭크 |
| 수·토 | 어깨 · 하체 · 복근 | 파이크 푸시업, 케틀벨 원암 숄더 프레스, 스쿼트, 케틀벨 데드리프트, 크런치, 플랭크 |
| 일 | 무제한 서킷 | 파이크 푸시업 5회 → 푸시업 10회 → 스쿼트 15회 → 휴식 30초 → 반복 |

부위당 1~2개 동작을 선택하고 30·40·50·60분에 맞춰 세트·횟수·유지 시간을 배분합니다. 세트 사이 30초, 운동 전환 60초입니다. 처음에는 선택 시간보다 약 1분 짧게 구성해 완만한 증가 여유를 둡니다. 일요일은 시간 선택 없이 반복하며 **서킷 끝내기**로 종료합니다. 동작 사이에는 쉬지 않고 한 바퀴 뒤에만 30초 쉽니다.

기본 장비는 맨몸과 케틀벨 12kg 1개입니다. 컨센트레이션 컬에는 흔들리지 않는 좌판이 필요합니다. 짧은 60cm 일자 밴드를 포함해 장비까지 정확한 그림이 없는 동작은 기본 루틴에 넣지 않습니다. 점프·준비·마무리 운동은 없습니다. 별도 점프 없는 유산소도 설정에서 선택할 수 있습니다.

## 강도와 성장

운동 중 **Normal / Hard / Extreme**을 선택하면 앞으로 할 반복 수와 세트 수가 바뀝니다. Hard는 기본 반복·시간의 약 15%와 선택 세트 1개, Extreme은 약 30%와 선택 세트 2개를 추가합니다. 현재 세트의 수량·타이머와 완료 기록은 유지합니다. 강도를 내려도 이미 시작·완료한 세트는 취소하지 않습니다. 완료한 운동 종류는 다시 추가하지 않습니다. 강도를 높이면 선택한 기본 시간보다 길어질 수 있습니다.

일요일 강도 변경은 앞으로 할 수량을 바꾸며 새 라운드는 한 바퀴가 끝날 때만 추가합니다. 종료 시 실제 완료한 세트를 기록합니다.

기본 동작부터 배치하고 여유 있게 완료한 기록으로 얻은 단계에 따라 운동량을 소폭 늘립니다. 4단계 이후 검증된 변형 동작을 일부 교체합니다. 달력 날짜나 새 동작이라는 이유로 난도를 올리지 않습니다. 힘들었다면 단계를 유지하고 하루 중복 상승을 막습니다. 단계·수량은 앱의 운영 규칙이며 개인별 효과를 보장하지 않습니다.

## 설정과 화면

루틴 선택·요일·운동 종류·프리셋 편집은 **설정 → 운동 설정**에 있습니다. 선택하면 YOUR ROUTINE의 제목·운동 목록·수량이 즉시 바뀝니다. 진행 중인 운동과 다음 선택을 분리해, 선택만으로 기존 완료 기록을 지우지 않습니다. 루틴 적용을 누르면 선택한 미리보기로 전환하며, 같은 루틴을 다시 적용하면 진행을 유지합니다. 기본 분할 외에 하루 4~5개 핵심 동작에 집중하는 추천 프리셋을 선택할 수 있습니다. 직접 편집한 프리셋도 유지합니다.

검정·하양·빨강을 사용하는 **다크 / 라이트** 두 모드입니다. 별도 색상 팔레트 없이 AI로 제작한 BR 아이콘을 사용합니다. [브랜드 자산 안내](assets/brand/README.md)에 제작 정보를 기록했습니다. 화면 모드는 여백을 둔 체크박스 형태의 단일 선택입니다. 화면 꺼짐 방지·알림 활성화·알림 테스트는 한 카드에 통합했고 저장 방식·운동 가이드 소스 설정 카드는 제거했습니다. iPhone 13 mini에서는 제목 아래 요일 간격을 늘리고 시간과 알림을 한 줄에 표시합니다.

저장 키 `burning-routine-local-v150`, 기존 할 일·기록·성장 트랙·저장 프리셋을 보존합니다. 진행 중인 세션은 새로고침 뒤 일시정지 상태로 복원됩니다. 과거 별도 미완료 목록은 표시하지 않습니다.

실사 영상과 3D는 사용하지 않습니다. 장비가 일치하는 해부학 GIF 64종을 지원합니다. 최초 조회에는 인터넷이 필요하며 본 그림은 캐시합니다. 출처는 운동 방법 아래에 있습니다. [외부 자료 안내](THIRD_PARTY_NOTICES.md)를 참고하세요.

화면 자동 꺼짐 방지는 앱이 보일 때 Screen Wake Lock을 요청합니다. 실제 유지 중·지원 안 됨·거부를 구분하며 브라우저와 기기 설정에 따라 동작합니다.

## 검증과 배포

```sh
node --test
node --check app.js
node --check service-worker.js
```

현재 Playwright 검증은 `scripts/settings-selection.cjs`(선택 미리보기·적용·기록 보존·모드·같은 줄 입력), `scripts/live-duration-controls.cjs`(운동 중 시간 변경·기록 보존·원형 아이콘), `scripts/compact-live.cjs`(미완료 탐색·자동 완료·강도·재실행·일요일 반복), `scripts/image-first-settings.cjs`(설정·모드·375/320px 입력), `scripts/iphone-fallback.cjs`(그림 실패)입니다. Chrome과 WebKit의 iPhone 13 mini 프로필을 사용합니다. 과거 버전 전용 브라우저 스크립트는 당시 수동 완료·별도 복구 UI의 기록입니다.

GitHub main 업로드 시 Workout checks와 Pages 배포가 자동 실행됩니다.
