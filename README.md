# BURNING ROUTINE 4.1

운동·할 일 관리 PWA. [앱 실행](https://rusicalis.github.io/B-ROUTING/?view=workout&release=410)

## 운동 화면

- 그림 우측 상단의30·40·50·60분 중 하나를 선택합니다. 일요일에도 네 시간을 모두 선택할 수 있으며, 기본은 평일·토요일30분/일요일40분입니다.
- 그림 오른쪽 위 ✓는 세트 완료, 휴식 중 나타나는 빠른 넘김 아이콘은 휴식 건너뛰기입니다. 이전 하단 고정 조작 카드는 없애 타이머가 가려지지 않게 했습니다.
- 그림을 누르면 운동/휴식이 일시정지되고 ▶가 나타납니다. 다시 누르면 계속됩니다. 그림 로딩에 실패해도 일시정지 아이콘은 사용할 수 있습니다.
- 좌우 삼각형은 이전/다음 운동 이동입니다. **이동은 완료 처리가 아닙니다.** 건너뛴 세트는 미완료로 남습니다.
- 다음 세트와 다음 운동 이름을 표시하고, '오늘 운동 순서'에서 전체 목록을 볼 수 있습니다. 휴식 중에는 실제 다음 세트의 그림이 재생되며, 운동 순서와 작업 타이머는 휴식이 끝날 때 넘어갑니다.
- 타이머 바로 아래에 운동 방법을 표시합니다. 단계 버튼·배속·스크럽과 기존 하단 설명 영역은 제거했습니다. 그림 출처는 운동 방법 아래에 표시합니다.

루틴 변경에서는 루틴 종류·요일·저장 프리셋만 빠르게 선택합니다. 운동량/브리지 변경과 이름 붙여 저장하기는 접힌 '상세 설정'에 있습니다. 직접 운동 선택도 지원합니다.

## 미완료 운동만 이어하기

중간 종료나 운동 건너뛰기 시 완료한 세트를 별도로 보존합니다. 종료 화면의 운동 그림 카드에서 **남은 세트만 운동**을 선택하면 해당 운동의 미완료 세트만 원래 강도로 재개합니다. 모든 남은 운동을 이어서 하는 버튼도 있습니다. 새로고침·앱 재실행 후에도 복원됩니다.

완료 버튼을 잘못 눌렀다면 그림 우측 위 ↶로 직전 세트를 취소합니다. 종료/최종 컨디션 화면의 '잘못 누른 완료 수정'에서는 운동 종류별 완료를 취소하고 다시 할 수 있습니다. 원래 루틴의 모든 세트가 채워진 후 컨디션까지 저장해야 전체 완료·단계 상승이 기록됩니다. 일부 운동만 끝냈다고 전체 완료를 기록하지 않으며, 완료 기록과 성장 단계는 하루 중복 상승하지 않습니다.

## 운동 종류와 시간 배분

그림이 검증된 운동25종(맨몸18·케틀벨7)을 추가해 활성 그림 가이드는 **64종**입니다. 맨몸 또는 케틀벨12kg1개 사용을 그림에서 확인했습니다. 케틀벨2개·벤치 등 다른 장비가 필요한 후보와 점프 동작은 추가하지 않았습니다. 숙련자용10종은 라이브러리에서 구분하며 기본 시간 맞춤에는 자동 배치하지 않습니다.

기본 시간 맞춤은 요청한 요일별 핵심 순서를 먼저 유지하고, 대상 부위에 맞는 **새 운동 종류를 우선 추가**합니다. 다음 시간 단계에서도 이미 배치한 동작·수량을 보존합니다. 더 넣을 동작이 없거나 시간 안에 들어가지 않으면 횟수·유지 시간·세트를 조절합니다. 보호된 기본 수량을 지키고, 실제 양쪽 운동 시간과 휴식만 합산해 예상 시간을 표시합니다. 숨은 휴식으로 시간을 채우지 않습니다. 보통 선택 시간보다1분 안팎 짧게 시작하며, 완료에 따른 완만한 증가를 위한 여유를 둡니다.

| 요일 | 유지하는 핵심 순서 |
|---|---|
| 월·목 | 푸시업 → 파이크 → 맨몸 삼두 익스텐션 → 의자 딥스 → 리버스 플랭크 |
| 화·금 | 케틀벨 원암 컬 → 원암 숄더 프레스 → 데드리프트 → 복근 → 프론 Y 레이즈 |
| 수·토 | 케틀벨 원암 로우 → 스쿼트 → 리버스 플랭크 |
| 일 | 로우 → 푸시업 → 스쿼트 서킷, 복근·리버스 플랭크 |

세트 사이30초, 운동 전환60초이며 마지막 세트 뒤 휴식은 없습니다. 준비·마무리 운동과 점프는 없습니다. 정확한 그림이 없는 원래 케틀벨 삼두·짧은 밴드 동작은 승인된 대체 동작을 기본으로 쓰고 요청 원안은 '원안 목표 수량'에 남깁니다. 목표 수량 모드는 자동 시간 맞춤과 구분하며, 일요일은4라운드+복근·리버스 플랭크5세트로 약36분입니다.

요청 배치에 따른 일→월 가슴·삼두, 월→화 어깨의 연속 사용 안내를 유지합니다. 이전 주간표의 모든 부위 주3회/연속일 없음 주장은 새 주간표에 적용하지 않습니다. 별도 점프 없는 유산소도 선택 시간에 맞춰 라운드를 배분합니다.

## 저장·그림·화면 유지

기존 할 일·테마·완료 기록·저장 키를 보존합니다. iPhone13mini의 일정 입력란은 두 줄로 배치해 시간·알림·제목이 겹치지 않도록 수정했습니다.

실사 영상과 실시간3D는 사용하지 않습니다. 원격 해부학 GIF는 처음 볼 때 인터넷이 필요하며 표시 후 캐시합니다. 출처·이용 조건 및 이미지 프록시 의존은 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 기재했습니다.

'화면 자동 꺼짐 방지'는 기본 켜짐이며 앱이 보일 때 Screen Wake Lock을 요청합니다. 다른 앱 전환·종료·설정 해제 시 해제하고 복귀하면 재요청합니다. 지원 안 됨·거부·실제 유지 중을 구분합니다. iOS Safari16.4 이상, 홈 화면 웹 앱18.4 이상의 지원이 필요하며 기기 정책으로 거부될 수 있습니다. 실제 iPhone 하드웨어의 자동 잠금 시간이나 배터리를 측정한 것은 아닙니다.

## 검증

```sh
node --check illustrated-guide.mjs
node --check service-worker.js
```
